# DESIGN.md

Visual design guide for the Nyx Foundation website. Facts are extracted from the current implementation (`src/app/globals.css`, `src/app/layout.tsx`, `src/components`); architecture and commands live in `AGENTS.md`.

## Visual language

- Monochrome and minimal: white background, pure-black text, gray secondary text. No brand accent color — status states use Tailwind default-palette colors (e.g. `text-emerald-600` for success).
- No site-level dark mode. The `[data-theme]` variables in `globals.css` exist only for react-tweet embeds.

## Design tokens

Source of truth: `:root` in `src/app/globals.css`, mapped into utilities via `@theme inline`.

| Token | Value |
| --- | --- |
| `--background` | `#ffffff` |
| `--foreground` | `#000000` |
| `--muted` | `#f5f5f5` |
| `--muted-foreground` | `#737373` |
| `--border` | `#e5e5e5` |
| `--card` | `#ffffff` |
| `--radius` | `0.5rem` |

- The mapping generates working utilities: `bg-background`, `text-foreground`, `text-muted-foreground`, `bg-muted` (incl. `/opacity`), `border-border`, `bg-card`. A base-layer rule sets the default border color to `var(--border)` (v3-like behavior; v4 would otherwise be `currentColor`).
- `body`: `line-height: 1.7` (tuned for Japanese copy), antialiased, `liga`/`kern` font features. Tokens are also consumed directly by plain CSS (body colors, `.skeleton-shimmer` gradient).

## Tailwind v4 setup — read before styling

- Theme is CSS-first in `globals.css`: `@theme inline` maps the `:root` tokens to utilities and `@theme` defines `--animate-fade-in` (used by the Radix Dialog). `tailwind.config.ts` was removed — Tailwind v4 never auto-loads JS configs; do not reintroduce one for colors, fonts, or screens.
- v3-era classes do not exist in v4 and generate nothing: `bg-opacity-*` (use opacity modifiers like `hover:bg-foreground/90`), and `animate-in` / `fade-in-0` / `zoom-in-95` from tailwindcss-animate (plugin absent — use `animate-fade-in`).
- Some older markup retains redundant default-palette classes (`border-gray-200`, `bg-white`, `border-gray-300`) left over while semantic utilities were unstyled; the semantic classes are now the tokens to trust.
- To extend the design, edit the `@theme` blocks in `globals.css` only.

## Typography

- Fonts via `next/font/google` on `<html>`: BIZ UDPMincho (400) and Noto Serif JP (400–700), exposed as `--font-biz-udp-mincho` / `--font-noto-serif-jp`.
- `body` is classed `font-serif`, resolved through `--font-serif` in `@theme inline` to the two brand fonts (serif-first identity), falling back to generic `serif`.
- Type scale in practice: hero `text-5xl md:text-7xl tracking-tight bold`; lead `text-xl md:text-2xl`; body `text-base md:text-lg`; secondary `text-sm`; captions `text-xs` / `text-[11px]`.

## Layout

- Content container: `max-w-6xl mx-auto px-4` is the dominant pattern (17 occurrences); text-heavy sections use `max-w-4xl` / `max-w-3xl`.
- Header: sticky `top-0 z-50`, `h-16`, bottom border, white background; the mobile menu locks body scroll and closes on resize ≥768px.
- Hero: `min-h-[500px]` with `hero.svg` background and a `bg-white/86.5` overlay for legibility; content in `max-w-6xl`.
- Primary button: solid black — `bg-foreground text-background rounded-md hover:bg-foreground/90`; focus style `ring-2 ring-offset-2`.
- Secondary button: outline — `border border-border rounded-md px-4 py-2 md:px-6 py-2.5 hover:bg-muted`.
- Section labels (eyebrow): `text-xs font-semibold uppercase tracking-[0.14em] text-muted-foreground`; one `tracking-[0.3em]` variant exists.

## Components

- `src/components/ui/` holds only `Skeleton` (`skeleton-shimmer` keyframes plus composable card/grid skeletons). There is no shadcn CLI setup (no `components.json`) — Radix primitives are wrapped directly (e.g. Dialog in `ActivityModal.tsx` with a `bg-black/50` overlay and `animate-fade-in`).
- There is no `primary` semantic token; hover accents use `hover:text-foreground` (e.g. `NewsTable`) and the loading spinner uses `border-foreground` (`loading.tsx`).
- Cards/surfaces: white, `border rounded-lg`, occasional `shadow-sm` / `shadow-lg`; tags render as `rounded-full` pills.
- Forms: inputs `border border-border rounded-md px-3 py-2` with `focus:ring-2`; full-width submit in solid black.
- Icons: lucide-react exclusively.
- Class composition: use `cn()` (`clsx` + `tailwind-merge`) from `src/lib/utils.ts`.

## Brand assets (public/)

- `icon.svg` — favicon + header logo; `hero.svg` — hero background; `ogp.png` — default OG image (1200×630, referenced by `layout.tsx` metadata); hand-curated asset dirs (`sponsors/`, `gallery/`, `activity/`).
- `notion-assets/` is generated by the Notion fetch script — do not hand-edit.
